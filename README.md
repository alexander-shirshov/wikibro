# WikiBro

Open-source self-hosted markdown wiki for developers and small teams.

## Status

Early development / MVP planning.

## Features

- Markdown-first content
- Draft/publish flow
- Media uploads
- Role-based access
- Optional Git sync
- Docker deployment

## Tech Stack

- Vue 3 + TypeScript
- Node.js + Fastify + TypeScript
- PostgreSQL
- Docker Compose
